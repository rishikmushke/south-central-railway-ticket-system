# south-central-railway-ticket-system
🚆 South Central Railway – Train Ticket Booking System

📌 About the Project

This project is a simple Train Ticket Booking System developed using Python. It is designed to manage basic railway operations, such as agent login, train information, station details, and searching for trains based on source and destination.

The main purpose of this project is to apply Python programming concepts and understand how Object-Oriented Programming works in a real-world application.

🛠️ Technologies Used

- Python
- NumPy
- Object-Oriented Programming (OOP)

✨ Features

- Agent Login using username and password
- User details management
- Train information storage
- Railway station and route information
- Search trains using source and destination
- Simple menu-driven interface

🧠 Python Concepts Used

- Classes and Objects
- Constructors ("__init__")
- NumPy Arrays
- For Loops
- Conditional Statements
- Match-Case Statements
- User Input and Output Operations

🚉 Train Routes

Currently, the project includes train information for the following route:

- Kacheguda to Kamareddy
- Intermediate stations and departure timings

▶️ How to Run the Project

Step 1: Clone the repository

git clone YOUR_REPOSITORY_URL

Step 2: Install NumPy

pip install numpy

Step 3: Run the Python file

python main.py
